# GPT와의 대화..

이번에는 AWS에서 제창한 AIDLC에 대해 내용을 GPT에 물어보고 정리를 시킨 것이다. 다음은 두번째



# AIDLC의 설치 

네. **Codex CLI에서** `$aidlc`**를 이용해 간단한 REST API 프로젝트를 개발하는 예시**를 보여드리겠습니다.

핵심은 `$aidlc` 명령 하나로 요구사항 분석 → 설계 → 구현 → 테스트로 이어지는 AI-DLC v2 워크플로를 시작할 수 있다는 것입니다.



## **1. 실습 목표**

Python FastAPI를 이용해 간단한 할 일 관리(TODO) API를 개발한다고 가정하겠습니다.

개발할 기능은 다음과 같습니다.

- 할 일 등록
- 할 일 목록 조회
- 할 일 완료 처리
- 할 일 삭제



## **2. AI-DLC 설치와 프로젝트 준비**

macOS 터미널 기준입니다. 이미 AI-DLC를 설치했다면 설치 명령은 생략할 수 있습니다.



```
# AI-DLC 설치
curl -fsSL https://github.com/awslabs/aidlc-workflows/releases/latest/download/install.sh | sh

# 프로젝트 생성
mkdir todo-api
cd todo-api
git init

# Codex용 AI-DLC 구성
aidlc config --harness codex

# 설정 검사
aidlc doctor

# Codex 실행
codex
```



`$aidlc`는 터미널 셸 명령이 아니라 **Codex에서 호출하는 Skill 이름**입니다. Codex에서 해당 스킬을 실행하면 AI-DLC 엔진이 작업에 맞는 워크플로를 선택하거나 제안합니다.



## **3.** `$aidlc` **실행**

이제 **Codex의 대화 입력창**에 다음과 같이 입력합니다.



```
{"$aidlc"}를 사용하여 Python FastAPI 기반의 TODO REST API를 개발해 줘.

요구사항:
1. 할 일 등록, 조회, 완료 처리, 삭제 기능
2. SQLite 데이터베이스 사용
3. pytest 기반 단위 테스트 작성
4. OpenAPI 문서 제공
5. Docker 실행 환경 구성

중요:
- 요구사항과 설계는 구현 전에 검토받을 것
- 각 단계의 결과를 설명할 것
- 테스트를 실행하고 결과를 보고할 것

```



aidlc에 대한 매뉴얼은 [소개 페이지](https://awslabs.github.io/aidlc-workflows/)를 참조하기 바란다.
